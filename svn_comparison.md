# Git и SVN

## Почему ветвление в Git дешёвое, а в SVN дорогое?

Git создаёт ветки как лёгкие ссылки на коммиты, поэтому операция выполняется практически мгновенно. В SVN ветвление традиционно связано с копированием структуры каталогов в централизованном репозитории.

## Можно ли в SVN сделать коммит без интернета?

Нет. SVN является централизованной системой, поэтому для создания коммита необходимо соединение с центральным сервером.

## Когда SVN может быть предпочтительнее Git?

Например, при сопровождении старых корпоративных систем, которые уже используют SVN и тесно интегрированы с существующей инфраструктурой.
